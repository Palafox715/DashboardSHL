# Transfer Tracker Project — Continuation Prompt

I am building a personal call center transfer tracking web app.

The goal is a fast, lightweight productivity tool for tracking approved and declined call transfers and accurately estimating bonus pay.

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* IndexedDB only
* No frameworks
* No backend
* No login

Priorities:

* Speed
* Keyboard-first workflow
* Minimal clicks
* Real-time tracking
* Mobile-friendly (400px width)
* Dark mode by default

# Current Bonus Rules

## Normal Days (Sunday-Friday)

Approved:

* 0–2 = $0
* 3–7 = every approved transfer pays $4.70
* 8+ = every approved transfer pays $5.85

Example:

8 approved:

```
8 × $5.85 = $46.80
```

Declined:

* 0–2 = $0
* 3+ = every declined transfer pays $1.75

---

# Saturday Rules

Saturday is automatically detected by transfer date.

No toggle.

If there are no transfers on Saturday, there is no Saturday calculation.

Approved:

* 0–1 = $0
* 2+ = every approved transfer pays $5.85

Declined:

* 0–2 = $0
* 3+ = every declined transfer pays $1.75

# Current Week Rules

Work week:

Wednesday → Tuesday

NOT Monday-Sunday.

Weekly bonus is calculated by summing each day's earned bonus.

Do not calculate weekly bonus from weekly totals because thresholds reset daily.
